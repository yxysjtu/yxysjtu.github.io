# 离散信号傅里叶分析（DTFT）

## 定义
x(t)以T间隔采样：$x[n]=x(nT)$
$$
X(e^{jw})=\sum x[n]e^{-jwn}
\\x[n]=\frac{1}{2\pi}\int_{-\pi}^{\pi}X(e^{jw})e^{jwn}dw
$$
相当于时域上采样，频域上周期（幅度会/T，对于非$\delta$而言；对于$\delta$不用/T），这个频域轴转换到实际频域轴只需要/T，即$2\pi$映射到$\dfrac{2\pi}{T}=f_s$

还有另外一个定义：
$$
X(e^{j2\pi f})=\sum x[n]e^{-j2\pi fn}
\\x[n]=\int_{-1/2}^{1/2}X(e^{j2\pi f})e^{j2\pi fn}df
$$
会更加简洁，$f\in (-\dfrac{1}{2},-\dfrac{1}{2})$。转换到实际频域就只需要频率轴xfs



频域(w)与频域(f)互相转换，当没有$\delta$时直接换元，当有$\delta$时这一项要$/2\pi$

## 应用

离散信号的频域分析


## 性质
| 性质         | 时域[n]                  | 频域(w)                                                      |
| ------------ | ------------------------ | ------------------------------------------------------------ |
| 时移         | $x[n-n_0]$               | $e^{-jwn_0}X(e^{jw})$                                        |
| 频移         | $e^{jw_0n}x[n]$          | $X(e^{j(w-w0)})$                                             |
| 差分         | $x[n]-x[n-1]$            | $(1-e^{-jw})X(e^{jw})$                                       |
| 求和         | $\sum_{-\infty}^{n}x[m]$ | $\dfrac{X(e^{jw})}{1-e^{-jw}}+\pi X(e^{j0})\sum_{-\infty}^{\infty}\delta(w-2\pi k)$ |
| 频域微分     | $(-jn)x[n]$              | $\dfrac{X(e^{jw})}{dw}$                                      |
| 时域卷积     | $x[n]\otimes h[n]$       | $X(e^{jw})H(e^{jw})$                                         |
| 频域环形卷积 | $x[n]y[n]$               | $\dfrac{1}{2\pi}\int_{-\pi}^{\pi}X(e^{j\theta})X(e^{j(w-\theta)})d\theta$ |
| 升采样M      | 每个采样点之间加(M-1)个0 | 频域中出现M个copy（宽度压缩M倍，幅度不变），在$2k\pi /M$分布 |
| 降采样M      | 每M个点取一个点          | 频域宽度扩大为M倍（如果出界则会混叠，幅度变为原来1/M）       |
| 能量         | $\sum (x[n])^2$          | $\dfrac{1}{2\pi}\int_{-\pi}^{\pi}X(e^{jw})X^*(e^{jw})dw$     |


## 变换对
| 时域[n]                    | 频域(w)                                           |
| -------------------------- | ------------------------------------------------- |
| $\delta[n]$                | 1                                                 |
| 1                          | $2\pi \sum \delta(w-2\pi k)$                      |
| $u[n]$                     | $\dfrac{1}{1-e^{-jw}}+\sum \pi \delta(w-2\pi k)$  |
| $e^{jw_0n}$                | $2\pi \sum \delta(w-w_0-2\pi k)$                  |
| $a^nu[n]\\-a^nu[-n-1]$     | $\dfrac{1}{1-ae^{-jw}}$                           |
| 矩形窗：1当$-M\le n \le M$ | $\dfrac{sin(w(M+\dfrac{1}{2}))}{sin\dfrac{w}{2}}$ |
| $\dfrac{sinw_cn}{\pi n}$   | 理想滤波器：1当$-w_c\le w \le w_c$                |

## 连续信号/连续频谱在计算机的计算
### 已知连续频谱（带宽有限），求冲激响应：
* 选择一个周期延拓时间间隔，使得冲激响应混叠不明显，这个周期延拓的频率就是频域采样间隔`df`
* 选择信号采样频率`fs=Ndf`，这样把N定下来
* 连续频谱先乘`fs`，转换为DTFT频谱，再采样N个点，最后用ifft转换，就可以得到冲激响应的N点采样序列

``` m
df=1;
N=1e7;

fs=df*N;
dt=1/fs;
HF1=zeros([N,1]);
for i=0:df:10e3
    HF1(i/df+1)=1-1/10e3*i;
end
for i=0:N/2-2
    HF1(N-i)=HF1(i+2);
end
h1=ifft(HF1*fs);
trange=0:5000;
subplot(1,2,1)
freq=-20e3:1:20e3;
freq_response=ifftshift(HF1);
plot(freq,freq_response(floor(N/2+freq/df)))
title("frequency response")
subplot(1,2,2)
plot(trange*dt*1e3,abs(h1(trange+1)))
xlabel("t/ms")
```

### 已知连续信号（时间有限），求连续频谱
* 根据信号带宽，确定采样频率`fs`，采样
* 求fft，然后幅度除以`fs`，截取一半数据
