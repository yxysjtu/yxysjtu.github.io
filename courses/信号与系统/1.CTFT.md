# 连续信号傅里叶分析（CTFT）
## 定义
$$
H(w)=\int_{-\infty}^{\infty}h(t)e^{-jwt}dt\\
h(t)=\dfrac{1}{2\pi}\int_{-\infty}^{\infty}H(w)e^{jwt}dw
$$
或者
$$
H(f)=\int_{-\infty}^{\infty}h(t)e^{-j2\pi ft}dt\\
h(t)=\int_{-\infty}^{\infty}H(f)e^{j2\pi ft}df
$$

## 应用

适于分析有某种周期性的信号/无限长有一定统计特征的随机过程的频域特征

## 性质

| 性质             | 时域                                  | 频域                                                         |
| ---------------- | ------------------------------------- | ------------------------------------------------------------ |
| 时移（线性相位） | $f(t-t_0)$                            | $e^{-jwt_0}F(w)$                                             |
| 微分             | $f'(t)$                               | $jwF(w)-jw\pi \delta(w)(f(\infty)+f(-\infty))$               |
| 积分             | $\int_{-\infty}^{t}f(\tau)d\tau$      | $(\dfrac{1}{jw}+\pi \delta(w))F(w)$                          |
| 频移（乘上正弦） | $e^{jw_0t}f(t)$                       | $F(w-w_0)$                                                   |
| 频域微分         | $(-jt)^nf(t)$                         | $\dfrac{d^n}{dw^n}F(w)$                                      |
| 时间轴伸缩       | $f(at)$                               | $\dfrac{1}{a}F(w/a)$                                         |
| 时间轴反向       | $f(-t)$                               | $F(-w)$                                                      |
| 共轭             | $f^*(t)$                              | $F^*(-w)$                                                    |
| 能量             | $\int_{-\infty}^{\infty}f(t)f^*(t)dt$ | $\int_{-\infty}^{\infty}F(f)F^*(f)df\;or\;\dfrac{1}{2\pi}\int_{-\infty}^{\infty}F(w)F^*(w)dw$ |
| 对称性           | $f(t)\\F(t)$                          | $F(f)\\f(-f)\;or\;2\pi f(-w)$                                |
| 时域卷积         | $f_1(t)\otimes f_2(t)$                | $F_1(w)F_2(w)$                                 |
| 时域乘积         | $f_1(t)f_2(t)$                        | $\dfrac{1}{2\pi}F_1(w)\otimes F_2(w)$           |

### 变换对
频域(w)与频域(f)互相转换，当没有$\delta$时直接换元，当有$\delta$时这一项要$/2\pi$
| 时域(t)                                                      | 频域(f)                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| $\delta(t)$                                                  | 1                                                            |
| 1                                                            | $\delta(f)$                                                  |
| $u(t)$                                                       | $\dfrac{1}{j2\pi f}+\dfrac{\delta(f)}{2}$                    |
| $sgn(t)$                                                     | $\dfrac{2}{j2\pi f}$                                         |
| 冲激串：$\sum_{n=-\infty}^{\infty}\delta(t-nT)$              | $\dfrac{1}{T}\sum_{n=-\infty}^{\infty}\delta(f-\dfrac{n}{T})$ |
| 矩形窗：$1, -\tau<t<\tau$                                    | $\dfrac{sinw\tau}{w/2}$                                      |
| $\dfrac{sin2\pi f_ct}{\pi t}=\dfrac{sinw_ct}{\pi t}$         | 理想滤波器：$1, -f_c<f<f_c$                                  |
| 钟形脉冲：$e^{-(\frac{t}{\tau})^2}$                          | $\sqrt{\pi}\tau e^{-(\pi f\tau)^2}$                          |
| 升余弦脉冲：$\dfrac{1}{2}(1+cos\dfrac{\pi t}{\tau}) \\(-\tau<t<\tau)$ | $\dfrac{\tau Sa(w\tau)}{1-(\dfrac{w\tau}{\pi})^2}, Sa(x)=\dfrac{sinx}{x}$ |

## 周期与采样
* 时域上周期，频域上采样
* 时域上采样，频域上周期（可能有混叠）

不管是时域上周期延拓还是时域上采样，都会导致频域上/T（指f频域，跟w频域还是有点区别的（在$\delta$的系数有区分））
